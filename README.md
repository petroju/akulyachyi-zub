# Акулячий Зуб

Кооперативна гра на виживання для компанії з 3–12 людей, яка грається просто в браузері.

Ваш корабель розбився біля острова. Ви разом будуєте пліт, збираєте воду та їжу й мусите відплисти до урагану. Але коли припасів не вистачає на всіх, табір голосує, кого вигнати.

**Грати:** https://petroju.github.io/akulyachyi-zub/

## Режими
- **Один телефон по колу.** Телефон передається від гравця до гравця.
- **Кожен зі свого телефона.** Один гравець створює кімнату й отримує код із 4 літер, інші вводять цей код. Реєстрація не потрібна. Телефон того, хто створив гру, працює як ведучий, тож на ньому не можна закривати сторінку, поки йде гра.

Уся гра міститься в одному файлі `index.html`. Для онлайн-режиму вона використовує [PeerJS](https://peerjs.com/).
